## 🚀 Featured Projects

### 🎥 [Aegivue](https://github.com/prinako/aegivue)

Self-hosted network video recorder designed for reliable RTSP recording, low-latency live viewing, and modern camera management.

**Highlights**

- Rust/Tokio media engine
- TypeScript + Fastify API
- Flutter web dashboard
- PostgreSQL metadata storage
- FFmpeg recording pipeline
- WebRTC + LL-HLS live streaming
- MediaMTX integration
- Docker Compose deployment
- Motion/event-processing foundation
- Per-camera workers and automatic recovery

`Rust` `TypeScript` `Flutter` `PostgreSQL` `Docker` `FFmpeg` `WebRTC`
